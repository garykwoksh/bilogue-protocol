## 六、什麼時候要加錢？

| 觸發條件 | 要加咩 | 月費變化 |
|----------|--------|---------|
| 多過 10 個 agent 同時跑 | 升級 VPS 到 CPX31 ($7.59) | +$3 |
| 需要 99.9% uptime SLA | 加 backup VPS | +$5 |
| 有付費用戶 | 加 Sentry 監控 + Better Uptime | +$26 |
| 月活過 1000 | 升級到 Hetzner dedicated ($35+) | +$30 |
| 要做 SaaS 後台 | 加數據庫 VPS + Redis | +$10 |

> **建議**：頭 6 個月唔使諗呢啲。$65.52/年 搞掂。等到有人話願意俾錢用，先至諗升級。
